# 盘镜 DiskLens

盘镜是一款 Windows 磁盘空间分析工具。扫描不写入目标磁盘，不要求管理员权限；查重和手动清理不依赖网络。

## 使用方式

- **便携版**：完整解压 `DiskLens-Portable-win-x64.zip`，双击其中的 `DiskLens.exe`。复制到另一台电脑时复制**整个解压目录**，不要只复制 EXE。
- **安装版**：运行 `DiskLens-Setup-win-x64.exe`。默认装到 `%LOCALAPPDATA%\Programs\DiskLens`，并创建开始菜单入口和 Windows 卸载项；不需要管理员权限。升级前请关闭盘镜。
- 目标是 **Windows 10 22H2 / Windows 11 x64**。运行时随包提供，不需要另装 .NET、Python 或其他运行环境。发行包未做代码签名，Windows 可能显示未知发布者提示；核对来源和 `SHA256.txt` 后再运行，不需要关闭系统防护。

## 扫描和清理

1. 点击左侧盘符或 **选择文件夹**，即可直接浏览当前一级目录、选择并移动文件，**无需先扫描**；此时大小显示“未扫描”，不计算子目录占用。点击 **扫描当前范围** 才在后台统计空间，可取消。已有扫描缓存的范围会恢复结果和上次浏览位置，切回来不重新扫描；缓存只在本次运行期间保留。
2. 点击空间地图色块，或双击列表中的文件夹进入下一级。点表头排序，按 `Ctrl+F` 按名称搜索已扫描范围。双击文件会在资源管理器中定位，不会运行它。搜索结果最多显示前 5,000 项。
3. 修改文件后（包括从盘镜移动、回收或彻底删除），点击 **刷新** 或按 `F5`。未扫描视图只重读当前一级，不触发空间扫描；已扫描视图只读变更目录并重试所有曾无法完整读取的目录，再更新列表、地图和大小，未变化的子树使用缓存。刷新保留当前文件夹，若它已经移除则回到最近的可读上级。跟踪中断、通知溢出或根目录被替换时会全量重扫；也可以手动点击 **全量重扫**。扫描不是磁盘快照，操作进行中可能看到中间状态，完成后可再刷新。
4. 使用 `Ctrl` / `Shift` 多选，再点击 **移动**、**移到回收站** 或 **彻底删除**。确认窗会列出所选路径。确认后任务在后台运行，**不限定提交任务数**，暂不能执行的任务按提交顺序排队。文件任务面板默认同时执行 4 项，可切换为 1／2／4／8 项；降低并行数不会中断已经开始的任务。移动和删除不会锁住空间浏览，也不会自动重扫。重叠任务和父子路径冲突仍会被拒绝。
5. **本地查重** 在当前目录及其子目录内按大小和抽样筛选，再以全文件 SHA-256 确认重复副本。不把指向同一文件实体的硬链接算作独立副本，不纳入零字节文件。即使哈希相同也请核对用途和备份，不要把所有副本都删除。

**移动**：在独立工作进程运行，工作进程异常退出会作为任务失败报告，不在主界面进程执行原生复制回调。同盘无合并时直接改目录项，不遍历子目录。跨盘非覆盖移动及目录合并使用有界队列、最多 8 个文件工作线程；只保留少量待处理文件和目录元数据，不为千万个文件建立完整复制清单。每个文件先完整复制到目标盘暂存位置，发布并核验后才移除对应原件；整个目录完成前，目标中可能已能看到部分文件。普通文件复制保留目标支持的附加数据流；加密或含附加数据流的目录会被保留并报告。跨盘目标使用目标目录权限，不保留硬链接关系。

流式移动不会遍历链接目标；可保留普通本地目录联接点和符号链接。相对链接保持原文本，指向本批次移动范围内的绝对链接会映射到对应新位置；外部绝对链接仍指向原位置。创建符号链接需 Windows 开发者模式或相应权限；不支持的重解析点、卷挂载或离线项会保留并报告。

- **同名冲突**：可跳过、覆盖，或选择 **合并（保留两份）**。合并逐层保留目标已有内容；同名普通文件用全文件 SHA-256 核对，无附加数据流且内容相同时保留目标并移除已核验原件；不同内容或类型冲突时，目标不变，来源用带 `盘镜保留-…` 的名称保存。覆盖仍替换整个同名目录、不合并，先将旧目标保留为同级 `盘镜覆盖备份-…`，再进行整项暂存和发布。大目录建议选择流式合并。受保护或不可安全处理的顶层同名项只能跳过。确认后新出现或已变化的顶层目标会被拒绝。
- **失败处理**：复制失败不移除该源文件，但其他已成功发布的文件可能已移动。若发布后原件被占用或改变，保留原件并报告。工作进程异常退出不自动重放；刷新后重新选择残留项、使用合并可核对目标已有副本。Windows 拒绝访问时可选择以管理员身份打开新窗口，原窗口的任务和缓存保留，不自动重试，也不修改权限。异常退出或权限限制可能留下 `.DiskLens-move-...` 暂存目录，请在确认没有相关任务并核对数据后再处理；软件不会自动搬走其他任务的暂存目录。
- **进度和耗时**：任务面板为每项任务显示进度条、当前阶段、已用时间及预计剩余／总耗时；跨盘复制还显示已复制字节和近期速度。大文件进度来自复制回调，小文件按字节和条目汇总，原件移除完成前不会显示为已完成。同盘改名可能瞬间完成。正在统计目录、等待前序任务或 Windows 确认、近期没有足够进度或进度停滞时显示正在估算，不虚构时间。时间会随磁盘负载变化，不是完成承诺。
- **后台队列**：可以继续添加任务，也可关闭进度面板后继续浏览，右下角 **文件任务** 可重新打开。最近 32 项已结束任务可查看详情，提交前失败或取消的操作见 **提交记录**。队列只在当前运行期间保留，有文件任务时不能退出主窗口。并行并非越多越快：机械盘或同盘竞争严重时建议降低并行数。

**删除**：未扫描视图禁用回收、彻底删除和查重，请先扫描。默认建议先用 **移到回收站**（限本机固定磁盘）。若 Windows 提示只能永久删除，请取消。**彻底删除** 是另一项独立操作，需要输入 `彻底删除` 并确认，绕过回收站且不能用盘镜撤销，不是安全擦除。删除文件夹前会复核扫描记录，文件在后台并行删除；被占用、权限不足或已变化的项会保留并报告。没有自动清理或清空回收站功能。

列表和地图统计的是**文件逻辑大小**，不是磁盘实际分配量或可释放空间。稀疏/压缩文件、硬链接、云文件、回收站和文件系统元数据可能使二者不同。磁盘容量来自 Windows。扫描不会跟随联接点、符号链接或离线项；“扫描详情”显示跳过计数，星号表示统计不完整。系统/程序目录、用户主目录本身、盘镜自身和扫描根不能移动或删除；未完整扫描的文件夹不能删除。正在被写入的文件请先关闭相关应用，再刷新并操作。

## 可选 AI 建议

在右上角 **AI 设置** 填写兼容 **Chat Completions** 的服务地址和 API Key。可填 `https://服务商域名/v1`，或填完整的 `/chat/completions` 或 `/models` 地址。远程服务要求 HTTPS；本机回环服务可用 HTTP，无需认证的服务可留空 Key。

点击 **拉取模型**，盘镜向同一服务请求 `/models`，在下拉框中显示接口返回的模型 ID，不发送文件信息。若服务没有提供模型列表，或模型不在列表中，可直接在框内手动填写。选好模型后建议点 **测试连接**（仅发送固定测试文本），再保存。列表有返回不代表其中所有模型都支持 Chat Completions；盘镜需要兼容接口的非流式文本响应。

选中 1–20 项后点 **AI 建议**。只有在预览并确认后才会发送所选项的名称、类型、逻辑大小、修改时间和已有的本地重复组编号（如有），不发送完整路径、文件内容或哈希。名称本身也可能敏感，请核对预览。AI 可以推测用途和给出人工核查建议，不能决定或执行文件操作。

设置保存在 `%LOCALAPPDATA%\DiskLens\settings.json`；默认不将 Key 写入磁盘，只有勾选记住时才以当前 Windows 用户的 DPAPI 加密保存。不随便携包迁移设置或 Key。卸载不删除设置；要移除它，可在 AI 设置清空并保存，或关闭盘镜后手动删除上述设置文件。

## 从源码一键打包

在 Windows x64 的本机 NTFS 工作目录中双击根目录的 `一键打包.cmd`，或运行 `powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\build\Package.ps1`。首次构建需要网络：脚本按固定版本和 SHA 校验引导 .NET SDK 与 NSIS，运行回归测试、发布自包含程序，然后生成便携 ZIP 与当前用户安装包。脚本会在新目录解压、隔离安装，逐个比对文件哈希、启动 WPF 自检，并验证卸载只删除已安装的文件。成功后产物位于 `release/`，测试报告及截图位于 `.agent-artifacts/package-last/`。

运行环境只需 Windows；构建工具和中间产物不会分发。应用源码在 `src/`，回归测试在 `tests/`，构建规则在 `build/`。
